# System Design Notes

A static, responsive personal blog for system-design study notes.

## Pages

- `index.html` — homepage and general-concept shelf
- `back-of-envelope.html` — capacity-estimation framework
- `dropbox.html` — Dropbox system-design case study

Open `index.html` in a browser to view the blog locally. It needs no build step or installation. The cream theme is the default; the theme switch remembers a reader's light/dark choice in their browser.

To add a new case study, create a new HTML page and link it from the **Use cases** section of the sidebar on each page.
